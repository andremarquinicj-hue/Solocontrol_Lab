# Solocontrol Lab v0.8.3

## O que mudou
A v0.8.3 implementa o novo Portal do Cliente no padrão visual aprovado.

### Principais itens
- menu lateral exclusivo do cliente;
- dashboard executivo da obra;
- indicadores de unidades, volume, ensaios, laudos e rastreabilidade;
- gráfico de evolução da obra;
- distribuição do volume por elemento;
- indicadores de qualidade e conformidade;
- mapa interativo com dossiê técnico do lote;
- últimas concretagens;
- galeria de evidências fotográficas;
- área de documentos e relatórios;
- PDF e compartilhamento por lote preservados.

## Atualização no GitHub
1. Extraia o ZIP da v0.8.3.
2. Substitua os arquivos da versão atual pelos arquivos desta versão.
3. Faça o commit. Sugestão: `Atualiza Portal do Cliente - v0.8.3`.
4. Aguarde o deploy automático do Vercel.
5. Quando ficar verde, abra `/portal-cliente` com um usuário autorizado.
6. Faça `Ctrl + F5` para limpar o cache antigo.

## Firebase
Não é necessário alterar as variáveis de ambiente nem as regras para esta atualização visual.
